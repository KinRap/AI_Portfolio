## About

I build AI systems that hold up to scrutiny - multi-agent architectures with deterministic audit layers instead of guesswork - and I can explain exactly why they work to the people who need to trust them. Background: a doctorate and two master's (theology and media education and journalism), coding since 2008, years teaching technology at university (UKSW), and intensive AI/ML reskilling (155h+).

## Featured work

- **TaskFlow Agentic Analytics** - a 6-agent LLM pipeline with a deterministic SQL audit layer that scores each agent on recall and precision (data-quality agent: recall 0.79 / precision 1.00). See `projects/taskflow.html`.
- **3DSmart AI Orchestrator** - a 5-agent system that automates renewable-energy tender analysis and delivers a GO / NO-GO executive report in under 6 minutes. See `projects/3dsmart.html`.
- **Technical Writing Portfolio** - structured authoring (DITA, MadCap Flare, Oxygen XML) and AI applied to documentation workflows. See `projects/tech-writing.html`.
